# Asociación C&C — NumisNotas

*NumisNotas* (also titled *NUMISTAS* on the masthead) is the periodical of the Asociación C&C, Medellín. Bernardo González White sat on the Comité NumisNotas.

© Asociación C&C. Working copies for Notofilia research. **Do not** republish plates, dealer ads, or price notes on the public site. Cite the issue (number, month, year, page), not a repo path.
