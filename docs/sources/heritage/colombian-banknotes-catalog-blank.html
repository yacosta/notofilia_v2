Colombian Banknotes

Blank catalog template with placeholder rows. Replace each card with a holding title, Pick, scan, and metadata. Layout and search follow the Heritage archive viewer.

Template scaffold only — no auction data or external images. Each row uses the same tuple shape as the Heritage extract: title, path, image id, lot id, date, price, Pick, grade. Swap placeholders for collection scans and Notofilia catalogue fields when you populate the grid.
