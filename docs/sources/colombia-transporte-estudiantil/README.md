## Classification

Popularly remembered and searched as a “billete.” **Technically it is not a banknote.** It is a printed **tiquete de subsidio** / **boleto de control** (student-transport subsidy ticket / control voucher).

When the piece is catalogued:

- Do **not** treat it as Banco de la República paper. Do not invent a Pick or González White BG# for it.
- Closest existing pattern on the site is miscellaneous scrip (e.g. Baraboo 1933), not a BanRep type row.
- In technical copy call it tiquete / vale / boleto de control. It is fair to say collectors of the period look for it as a “billete.”
- Identity is still the printed serial if one exists. A 5-centavos student ticket with a different serial is a different object.
